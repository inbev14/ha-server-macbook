# HA Server (MacBook Edition) v5

Нативний застосунок для macOS (Intel), який перетворює MacBook на стабільний сервер Home Assistant через UTM віртуальну машину.

## Особливості архітектури v5
- **Відокремлена логіка:** Системні налаштування (`Installer.sh`) відділені від коду програми (`App.swift`).
- **Графічні налаштування:** Управління адресами HA, таймерами та Webhook-пушами через нативне вікно Preferences.
- **Швидка збірка:** Скрипт `Build.command` компілює Swift-код у готовий застосунок `.app` за 1 секунду.
- **Апаратний захист батареї:** Інтегровано утиліту `bclm` (ліміт SMC 77 ≈ 80%) та аварійне засинання при 20% заряду.
- **Автоматична генерація YAML:** Застосунок створює пакет конфігурації для Home Assistant із захищеними Webhook ID.

## Встановлення з нуля (через GitHub)

Якщо ви встановлюєте програму на новий Mac, виконайте ці команди у Терміналі:

1. **Завантажте проєкт:**
   ```bash
   git clone [https://github.com/inbev14/ha-server-macbook.git](https://github.com/inbev14/ha-server-macbook.git)
   cd ha-server-macbook
2. Налаштуйте конфігурацію: 
   ```bash
   cp config.example.conf config.conf
3. Запустіть системне встановлення:
   ```bash
   ./Installer.sh
4. Скомпілюйте програму:
   ```bash
   ./Build.command

## Перевстановлення або оновлення 

1. **Встановлення системних служб:**
   Відкрийте Термінал, перетягніть у нього файл `Installer.sh` та натисніть Enter. Скрипт попросить пароль адміністратора для встановлення `bclm` та привілейованого хелпера.
2. **Компіляція програми:**
   Двічі клікніть по файлу `Build.command` у Finder (або запустіть у Терміналі або `./Build.command`). Скрипт збере програму та запустить її у верхньому рядку меню (значок 🟢 HA). або cd ~/Documents/HA-Server-Project && ./Build.command
3. **Налаштування:**
   Натисніть на значок `🟢 HA` -> **Налаштування...**. Вкажіть ваші локальні та хмарні адреси Home Assistant і назву служби push-сповіщень телефону.
4. **Інтеграція з Home Assistant:**
   Перенесіть згенерований файл `~/Documents/HA-Server-v3/ha_server_macbook_package.yaml` у папку `/config/packages/` вашого Home Assistant та перезавантажте сервер, якщо не спрацювало то без конфг одразу в packages/.

## Перевірка
Щоб перевірити працездатність програми файл `./check.command`

## Як вносити зміни (для розробників)
Якщо ви хочете змінити логіку програми або інтерфейс:
1. Відкрийте файл `App.swift` у будь-якому текстовому редакторі (наприклад, VS Code або TextEdit).
2. Внесіть необхідні зміни.
3. Двічі клікніть `Build.command` або `./Build.command`. Програма миттєво перезірбереться та перезапуститься з новими функціями.

## Вимоги
- MacBook на базі процесора **Intel** (Apple Silicon не підтримує апаратний ліміт заряду через SMC).
- macOS Monterey (11.x) або новіше.
- Встановлений Xcode Command Line Tools (`xcode-select --install`).
- Встановлений UTM з віртуальною машиною Home Assistant.

## Файли
- `App.swift` — вихідний код програми (Swift/AppKit).
- `Build.command` — скрипт збірки `.app`.
- `Installer.sh` — встановлення root-прав та `bclm`.
- `check.command` — діагностика системи та живлення.
- `uninstall.sh` — повне видалення програми та відновлення налаштувань.

Після того, як ви запустили ./Installer.sh на вашому Mac, у папці з проєктом з'явився готовий файл ha_server_macbook_package.yaml (а також захищений файл webhook-ids.conf із вашими унікальними ключами).

1. Перенесення файлів у Home Assistant
Скопіюйте файл ha_server_macbook_package.yaml на ваш сервер Home Assistant (у папку конфігурації /config/).

Для ідеального порядку краще покласти його в спеціальну папку для пакетів (якщо вона у вас налаштована): /config/packages/ha_server_macbook_package.yaml.(Якщо папки packages немає, треба створити). Проте у мене запрацювало коли поклав просто у папку packages/ha_server_macbook_package.yaml, без config.

2. Активація пакування в configuration.yaml
Щоб Home Assistant побачив цей файл і автоматично створив усі сенсори, автоматизації та інпути, у вашому головному файлі configuration.yaml має бути ввікнена підтримка пакетів. Додайте туди ці рядки (якщо їх ще немає):

YAML
homeassistant:
  packages: !include_dir_named packages
(Або якщо ви поклали файл в інше місце, підключіть його згідно з вашою структурою).

3. Перезавантаження Home Assistant
Зайдіть в Home Assistant: Налаштування -> Система -> Керування сервером (Server Controls).

Натисніть Перевірити конфігурацію (Check Configuration).

Якщо все ок — натисніть Перезавантажити (Restart) YAML-конфігурації або всього сервера.

Після цього в Home Assistant миттєво з'являться:

Сенсор віку зв'язку (sensor.macbook_server_heartbeat_age).

Текстовий статус (input_text.ha_server_macbook_status).

Дві автоматизації для прийому вебхуків (локального та хмарного), які стежитимуть за зарядом батареї та надсилатимуть сповіщення, якщо Mac розряджається або втрачає зв'язок.
