# HA Server (MacBook Edition) v5

Нативний застосунок для macOS (Intel), який перетворює MacBook на стабільний сервер Home Assistant через UTM віртуальну машину.

## Особливості архітектури v5
- **Відокремлена логіка:** Системні налаштування (`Installer.sh`) відділені від коду програми (`App.swift`).
- **Графічні налаштування:** Управління адресами HA, таймерами та Webhook-пушами через нативне вікно Preferences.
- **Швидка збірка:** Скрипт `Build.command` компілює Swift-код у готовий застосунок `.app` за 1 секунду.
- **Апаратний захист батареї:** Інтегровано утиліту `bclm` (ліміт SMC 77 ≈ 80%) та аварійне засинання при 20% заряду.
- **Автоматична генерація YAML:** Застосунок створює пакет конфігурації для Home Assistant із захищеними Webhook ID.

## Встановлення з нуля (через GitHub)

Якщо ви встановлюєте програму на новий Mac, виконайте ці команди у Терміналі:

1. **Завантажте проєкт:**
   ```bash
   git clone [https://github.com/inbev14/ha-server-macbook.git](https://github.com/inbev14/ha-server-macbook.git)
   cd ha-server-macbook
2. Налаштуйте конфігурацію: 
   cp config.example.conf config.conf
3. Запустіть системне встановлення:
   ./Installer.sh
4. Скомпілюйте програму:
   ./Build.command

## Встановлення 

1. **Встановлення системних служб:**
   Відкрийте Термінал, перетягніть у нього файл `Installer.sh` та натисніть Enter. Скрипт попросить пароль адміністратора для встановлення `bclm` та привілейованого хелпера.
2. **Компіляція програми:**
   Двічі клікніть по файлу `Build.command` у Finder (або запустіть у Терміналі). Скрипт збере програму та запустить її у верхньому рядку меню (значок 🟢 HA). або cd ~/Documents/HA-Server-Project && ./Build.command
3. **Налаштування:**
   Натисніть на значок `🟢 HA` -> **Налаштування...**. Вкажіть ваші локальні та хмарні адреси Home Assistant і назву служби push-сповіщень телефону.
4. **Інтеграція з Home Assistant:**
   Перенесіть згенерований файл `~/Documents/HA-Server-v3/ha_server_macbook_package.yaml` у папку `/config/packages/` вашого Home Assistant та перезавантажте сервер.

## Перевірка
Щоб перевірити працездатність програми файл `check.command`

## Як вносити зміни (для розробників)
Якщо ви хочете змінити логіку програми або інтерфейс:
1. Відкрийте файл `App.swift` у будь-якому текстовому редакторі (наприклад, VS Code або TextEdit).
2. Внесіть необхідні зміни.
3. Двічі клікніть `Build.command`. Програма миттєво перезірбереться та перезапуститься з новими функціями.

## Вимоги
- MacBook на базі процесора **Intel** (Apple Silicon не підтримує апаратний ліміт заряду через SMC).
- macOS Monterey (11.x) або новіше.
- Встановлений Xcode Command Line Tools (`xcode-select --install`).
- Встановлений UTM з віртуальною машиною Home Assistant.

## Файли
- `App.swift` — вихідний код програми (Swift/AppKit).
- `Build.command` — скрипт збірки `.app`.
- `Installer.sh` — встановлення root-прав та `bclm`.
- `check.command` — діагностика системи та живлення.
- `uninstall.sh` — повне видалення програми та відновлення налаштувань.
