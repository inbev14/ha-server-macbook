# Як налаштувати config.conf

Перед першим встановленням перейменуйте файл `config.example.conf` на `config.conf` і заповніть його вашими даними. Ось де їх знайти:

### 1. UTM_VM_UUID (Ідентифікатор віртуальної машини)
Програма автоматично запускає вашу віртуальну машину при старті Mac. Щоб вона знала, яку саме машину запускати:
- Відкрийте Термінал.
- Введіть команду: `/Applications/UTM.app/Contents/MacOS/utmctl list`
- Скопіюйте довгий код (UUID) навпроти вашої машини "Home Assistant" (наприклад, `98F4A813-2088-46B9-BD08-B26CC6D54239`).

### 2. NOTIFY_SERVICE (Служба push-сповіщень телефону)
Щоб Home Assistant міг надсилати вам повідомлення про розряд батареї:
- Відкрийте Home Assistant на телефоні або ПК.
- Перейдіть у **Налаштування** -> **Пристрої та сервіси** -> вкладка **Об'єкти** (Entities).
- У пошуку введіть `notify.mobile_app`.
- Скопіюйте точний ідентифікатор вашого пристрою (наприклад, `notify.mobile_app_sm_s921b`).

### 3. HA_LOCAL_URL та HA_REMOTE_URL
- **Local:** Ваша внутрішня IP-адреса та порт (зазвичай `http://192.168.X.X:8123`).
- **Remote:** Ваша доменна адреса для зовнішнього доступу, якщо є. Якщо немає — залиште порожнім або продублюйте локальну адресу.

### 4. HEARTBEAT_INTERVAL
Час у секундах (мінімум 10), з яким програма надсилає статус батареї та екрана на сервер Home Assistant.
